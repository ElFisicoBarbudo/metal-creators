# Metal CREATORS · Landing page

Web estática (HTML + CSS + JS, sin dependencias) del hub Metal CREATORS, pensada para enviar a marcas.

## Cómo actualizarla

Todos los datos están al final de `index.html`, en el bloque `DATOS`:

- `CREATORS`: handle, seguidores (en miles) por plataforma, bio y canción de cada creador. Las fotos están en `assets/creators/`.
- `CONTENT`: piezas colaborativas. Rellena `url` con el enlace al reel y la tarjeta pasará a abrirlo.
- `PARTNERS`: marcas y festivales que aparecen en la cinta y en la sección de marcas.

## Publicación

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
